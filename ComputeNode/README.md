# ColorTransferLab Backend

Browser-based ComputeNode for ColorTransferLab.

Set the following Space secret before starting the Space:

```text
COMPUTENODE_WEB_PASSWORD=<your-password>
```

The login username is `hpotechius`. The reduced database is downloaded from
the ColorTransferLab dataset on first startup.
